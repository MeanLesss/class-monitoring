# We install ultralytics-opencv-headless (the official headless build of
# ultralytics) instead of plain ultralytics. The plain one forces the
# non-headless `opencv-python`, which needs system libs (libGL, libglib2.0-0)
# that Streamlit Community Cloud's Debian Bullseye image cannot provide
# (libglib2.0-0 -> libffi7 missing). The headless build uses
# `opencv-python-headless` and needs NO graphics system libraries, so it runs
# cleanly on the free cloud tier (CPU-only, ~1GB RAM).
#
# If you also run the local WebRTC app (app.py, live streaming), install the
# extras separately:  pip install streamlit-webrtc av
